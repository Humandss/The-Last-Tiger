# 출격 후 조작 교범 화면 — 설계

작성일: 2026-06-14
대상 구간: `BriefingScene` → `SampleScene` 전환

## 개요

브리핑 씬에서 "출격" 버튼을 누른 뒤 곧바로 게임 씬으로 넘어가는 대신,
**전차 조작 교범 화면**을 한 단계 끼워 넣는다.
플레이어가 조작 키와 음성 지휘 방식을 숙지한 뒤 전투에 진입하도록 한다.

## 동작 흐름

1. "출격" 버튼 클릭
2. 화면의 **텍스트(글자) 레이블만 페이드아웃**한다.
   전장 배경 이미지·스캔라인·지도·로고 등 비텍스트 요소는 **그대로 유지**한다.
3. 같은 배경 위로 **"Panzerkampfwagen VI Tiger 교범"** 화면을 페이드인한다.
4. 플레이어가 **아무 키나** 누르면 다음으로 진행한다. (음성 PTT 키 `V`는 제외)
5. 화면 전체를 검정으로 페이드한 뒤, 기존 **전환 카드**(작전명·위치·시각)를 거쳐
   `SampleScene`을 로드한다. — 5단계는 기존 `BriefingSceneLoader` 흐름을 그대로 재사용.

## 화면 내용 (조작 교범)

- 레이아웃: 역할별 4분할 + 하단 음성 지휘 바. 모든 글자 가운데 정렬, 군사 교범 톤(골드 강조).
- 항목:
  - **차체 기동** — `W/S` 전·후진 · `A/D` 좌·우 선회 · `Space` 급정지 · `Shift/Ctrl` 속도 강·약
  - **주포·사격** — `F` 조준 · `좌클릭` 사격 · `E/Q` 사거리 ± · `휠클릭` 목표 지정 · `T` 사격 중지 · `Y` 차체 정렬
  - **장전** — `1` 철갑탄(AP) · `2` 고폭탄(HE) · `R` 직전 탄종 재장전
  - **시점** — `우클릭` 조준경 줌 · `Tab` 전차 내부 상태
  - **🎤 음성 지휘** (※ 서버 연결 필요) — `V` 누르고 말하기 ("포수, 사격" / "철갑탄 장전")
- 하단: "▸ 아무 키나 눌러 전투 개시 ◂" 진행 안내.

## 곁가지 변경 — `V` 키 충돌 해소

현재 `V` 키가 두 곳에 중복되어 있다.
- `CommanderController.freeLookToggleKey` — 자유 시점 토글
- `VoiceRealtimeClient.pttKey` — 음성 PTT

자유 시점 기능은 사실상 사용하지 않으므로 **`CommanderController`의 자유 시점 기능을 제거**한다.
그 결과 `V`는 음성 전용이 되어 충돌이 사라진다.

## 구현 방식

- `MissionBriefingUI.FinishBriefing()`을 수정한다. 현재는 루트 `CanvasGroup` 전체를 한 번에
  페이드아웃하지만, 이를 다음 순서로 분리한다.
  1. **텍스트 레이블만 페이드아웃** — 기존 `_allLabels` 리스트를 재활용하고 배경 레이어는 유지
  2. **교범 화면 빌드·페이드인**
  3. **아무 키 입력 대기** (`V` 제외)
  4. 기존 `OnBriefingComplete` 호출 → `BriefingSceneLoader`의 전환 흐름으로 이어짐
- 교범 화면은 프리팹 없이 기존 `BuildCanvas` / `AddLabel` 런타임 빌드 패턴을 그대로 따른다.
- 오디오(BGM/앰비언트)는 교범 화면 동안 계속 재생하다가, 4단계 이후 기존 페이드아웃 타이밍에 맞춰 정리한다.
